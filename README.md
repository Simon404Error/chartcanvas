# 统计图绘制面板 · ChartCanvas

一个 **通用可视化画图桌面工具**：打开任意 **Excel / CSV** 数据，即可在左侧选择字段、中间实时预览、右侧深度自定义样式，绘制**多种统计图**。借鉴企业数据分析项目的「数据解析 + 交互面板」思路，做成独立、通用的桌面应用（原生窗口，非网页版）。

完全离线运行，数据不离开本机。

## 快速开始

1. 双击 **`启动ChartCanvas.bat`**。
2. 点顶部 **「✨ 加载示例数据」** 立即体验，或 **「📂 打开 Excel / CSV」** 选择自己的数据（支持 `.xlsx .xls .csv .tsv .txt`）。
3. 左侧选字段 → 选图表类型 → 右侧调样式，图表实时更新。
4. **「⬇ 导出 PNG / SVG」** 保存图片。

## 支持的图表（11 种）

柱状图（分组/堆叠/横向） · 折线图 · 面积图 · 散点气泡 · 饼图环图 · 直方图 · 箱线图 · 热力图 · 雷达图 · 帕累托图 · 统计概要表格

## 高度自定义

- 字段：X/Y 多选、按列系列分组、数值聚合（求和/均值/中位/最大/最小/计数/去重计数）、数据筛选
- **✏️ 可编辑数据表**：内置可编辑表格，改/加/删数据后图表实时更新
- 样式：标题、宽高、字体字号、配色主题、背景（白/浅/深）、图例横排、对数轴
- 每类专属细节：堆叠、横向、显示数值、小数位、轴标题、透明度、线宽、曲线平滑、空心环比例、分箱数、色带、标签旋转、气泡放大等
- Plotly 原生交互：缩放、平移、悬停读数、模式栏、双击复位

## 数据兼容

- Excel `.xlsx` / `.xls`（多工作表自动取首个含数据表，含旧版 xls）
- CSV / TSV（自动识别 UTF-8 / GBK 等编码）

## 技术栈

- **pywebview**：原生桌面窗口
- **Python + Pandas**：后端解析 Excel/CSV、类型识别、分组筛选
- **Plotly.js**：本地离线渲染（无需联网/无外部 CDN）
- 独立 venv 环境，不污染系统

## 目录结构

```
ChartCanvas/
├── 启动ChartCanvas.bat       # 一键启动
├── requirements.txt
├── app/
│   ├── main.py               # 后端：文件选择、Excel/CSV 解析、查询
│   ├── sample_data.py        # 生成演示数据
│   ├── test_backend.py       # 后端冒烟测试
│   └── web/                  # 前端 (index.html / app.js / style.css / lib/plotly.min.js)
└── venv/                     # 独立 Python 环境
```

## 说明

- 详细使用见仓库内 `使用说明.md`。
- 依赖独立装入 `venv\`；系统需 Microsoft Edge WebView2 运行时（Win10/11 一般自带）。
- 后端数据接口返回原始列数组，聚合统一在前端 JS 完成，便于扩展新图类型。
